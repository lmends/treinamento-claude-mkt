# Quickstart: validar slides e subpáginas

1. Duplo clique em `index.html`: capa com "Apresentar" e "Estudar".
2. "Apresentar": pressione F (tela cheia) e → até o fim. Observe as transições, os cards
   entrando, as conversas digitando e o carrossel surgindo ao lado do chat no Módulo 5.
3. Pressione O (visão geral), N (notas), B (tela preta), 3 (Módulo 3). Recarregue: mesmo slide.
4. Volte à capa e abra "Estudar": artefatos aparecem abaixo das respostas; clique em
   "Ver animação"; marque "Concluí este módulo"; recarregue e veja o ✓.
5. Redimensione para 375 px: slides rolam por dentro, deslizar troca de slide; no estudo, o
   comparativo vira abas.

Testes: `cd tests && npm install && npx playwright install chromium && npx playwright test`.
